# Sponsio Points Checklist

Use this as the final pre-submission checklist. Never claim an item without opening its evidence link in an incognito browser.

## Basic points

- [x] Public GitHub repository
  - Evidence: <https://github.com/PradyunKedia/Monad_Hack>
  - Confirmed accessible without repository authentication on 2026-08-29.
- [ ] Proper README with live page and contract address
  - Evidence: the first section of `README.md`
  - Action: replace both `deployment pending` values after deployment.
- [ ] Smart contract deployed on Monad Testnet
  - Evidence: Monadscan contract page and `deployments/monad-testnet.json`

## Project working points

- [x] Announced functions implemented and tested
  - Evidence: contract, backend, frontend, and 100-client load suites.
- [ ] Live on-chain transaction during the demo

- [x] Reproducible without author assistance
